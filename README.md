**Kennesaw State University Senior Capstone | Spring 2026**

**Team Technology:** Unity • C# • GONet • Steamworks.NET

## About the Project

Beginning in the 1960s and continuing into the early 1990s, bathtub races were a memorable part of student life at Southern Polytechnic State University.

The races combined engineering creativity, competition, and campus camaraderie and remain an important part of SPSU history.

The goal of this project was to commemorate that tradition through an interactive racing game while creating a software project that future KSU students could continue to develop.

## 🚀 Running the Project

### Playing the Game

1. Download the available game build from the project resources.
2. Extract the downloaded folder.
3. Run `SPSU Racing Game.exe`.

### Opening the Source Code

1. Install GitHub Desktop or another Git client.
2. Clone this repository.
3. Install Unity Hub.
4. Install **Unity 2023.2.22f1**.
5. Add the cloned project through Unity Hub.
6. Open the project using Unity **2023.2.22f1**.
7. Open the bootstrap scene:

`Assets/Scenes/Bootstrap.unity`

8. Press Play.

GONet may occasionally cause Unity to stop Play mode while scripts recompile. If that occurs, allow recompilation to complete and press Play again.
